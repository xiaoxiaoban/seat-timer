# 拼豆座位计时工具
该工程为前后端分离，vue3+springboot+mysql技术栈，maven构建，在手机端浏览器浏览方便拼豆等类型店内座位的计时以及历史记录的查看。座位可在画布上自定义拖拽。部署文档参考DEPLOY.md。
